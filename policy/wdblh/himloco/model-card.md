# 模型说明

当前模型文件为 `himloco1_fix_qcs8550_fp16.qnn248.ctx.bin.aidem`。
文件来自原机工程，提取时未重新导出、转换或修改。
SHA-256 见工程根目录的 [SHA256SUMS](../../../SHA256SUMS)。

## 运行接口

| 项目 | 原机约定 |
| --- | --- |
| 后端 | AidLite `TYPE_QNN248` 和 `TYPE_DSP` |
| 输入形状 | `[1, 276]`，每帧 46 维，共 6 帧 |
| 输出形状 | `[1, 12]` |
| 数值类型 | 原机说明为 FP16；C++ 接口使用 `float32`，SDK 负责转换 |
| 历史顺序 | `time` 优先；索引为 `[0, 1, 2, 3, 4, 5]`，0 表示最新帧 |
| 配置 | 本目录的 [config.yaml](config.yaml) 和上级 [base.yaml](../base.yaml) |
| 控制周期 | 0.001 s，即 1,000 Hz |
| 策略周期 | 0.001 s × 20 = 0.02 s，即 50 Hz |

每帧观测按以下顺序拼接：

| 顺序 | 字段 | 维数 |
| --- | --- | --- |
| 1 | `commands` | 3 |
| 2 | `height` | 1 |
| 3 | `ang_vel` | 3 |
| 4 | `gravity_vec` | 3 |
| 5 | `dof_pos` | 12 |
| 6 | `dof_vel` | 12 |
| 7 | `actions` | 12 |

## 环境与检查

模型需要匹配目标设备的 AidLite SDK、QNN248 DSP 插件和授权。
构建与纯推理检查见[项目 README](../../../README.md)。

离线检查已验证配置布局和文件完整性，尚未执行 DSP 推理。
表中形状来自代码与原机接口约定，实际张量元数据仍需目标环境确认。

## 源模型与替换

旧 `himloco.onnx` 为 270 维，未纳入独立工程，不能直接替换当前模型。
当前模型转换前的 `himloco1.onnx` 在源副本中缺失。
因此，现有交付无法完成 ONNX 与 QNN 的数值一致性验证。

训练代码版本、训练检查点、导出命令、转换命令和完整 SDK 版本，
仍需由模型提供者补充。
